# Provenance

## Source
Bend Bulletin, July 3, 1912 — emblem reproduced at large scale.

Project archival reference:
https://oregonnews.uoregon.edu/lccn/sn96088235/1912-07-03/ed-1/seq-28/

The raster source included here is the image supplied to the reconstruction workflow. It should be replaced or supplemented with the archive's highest-resolution original scan if that file is later obtained.

## Important distinction
This package is a reconstruction **from a published newspaper impression**, not from the original 1912 drawing or printing cut. Newspaper ink spread, paper, photography/scanning, and later image processing can all alter local geometry.

Accordingly, this package records judgment calls instead of claiming perfect identity with lost original artwork.
